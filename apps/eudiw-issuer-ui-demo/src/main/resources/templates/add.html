Legg til bevistype

Det kan ta inntil eitt minutt før bevisdefinisjonen er oppdatert hos utferdaren.

Gyldige verdiar for type (datatypar) er:

  1. string: for tekst
  2. boolean: for boolske verdiar (true/false)
  3. number: positive tal (Java Integer: 2³¹ - 1)
  4. iso_date: ISO 8601-formatet YYYY-MM-DD som string, til dømes "2026-12-31"
  5. iso_date_time: ISO 8601-formatet YYYY-MM-DDThh:mm:ssZ som string, til dømes "2025-11-10T10:30:00Z"
  6. binary: for binære data, til dømes bilete, som er base64-koda. mime_type gjeld berre for binary-typen og må oppgjevast som medietype i tråd med RFC 2397. Standardverdien er "image/png" for SD-JWT, og attributtet blir ikkje brukt for MDoc.

Dersom type ikkje er oppgjeven, blir string brukt som standardverdi.
